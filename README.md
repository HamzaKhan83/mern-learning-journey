## ▶️ Running the Project

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd mern-learning-journey
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
